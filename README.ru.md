# Vacancy Application Bot

[English](README.md) | [Русский](README.ru.md)

Telegram-бот для сбора заявок на вакансии. Соискатель заполняет пошаговую анкету, проверяет введённые данные и отправляет заявку администратору.

## Возможности

- Пошаговая анкета на aiogram FSM
- Поля: ФИО, возраст, город, направление, опыт работы, информация о себе, телефон и фотография
- Отмена и перезапуск анкеты
- Проверка полей и безопасное экранирование HTML
- Отправка фотографии и данных заявки администратору
- Сохранение незавершённой отправки при ошибке Telegram, чтобы можно было повторить попытку
- Модульные тесты и автоматическая проверка через GitHub Actions

**Язык интерфейса бота:** русский.

## Требования

- Python 3.10 или новее
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather)
- Числовой Telegram ID администратора
- Зависимости из `requirements.txt`

## Установка

```bash
git clone https://github.com/parviz-rahmonov/Vacancy-Application-Bot.git
cd Vacancy-Application-Bot
python -m venv .venv
```

Активация окружения:

- Windows PowerShell: `.venv\Scripts\Activate.ps1`
- Linux/macOS: `source .venv/bin/activate`

Установка библиотек:

```bash
python -m pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните:

```dotenv
BOT_TOKEN=ваш_токен_бота
ADMIN_ID=123456789
```

Не загружайте настоящий `.env` в GitHub и не передавайте токен посторонним.

Запуск:

```bash
python main.py
```

Администратор должен сначала открыть диалог с ботом, иначе Telegram может запретить отправку сообщений.

## Тестирование

```bash
python -m unittest discover -s tests -v
```

Файл `.github/workflows/tests.yml` настраивает автоматический запуск тестов в GitHub Actions при push и Pull Request. Успешные тесты не заменяют проверку работающего бота в Telegram.

## Как работает бот

1. Соискатель отправляет `/start` и начинает анкету.
2. Бот последовательно собирает и проверяет данные.
3. Соискатель прикрепляет фотографию и проверяет анкету.
4. После подтверждения бот отправляет фото и текст заявки администратору.
5. Если отправка завершилась ошибкой, данные анкеты остаются для повторной попытки.

## Ограничения текущей версии

- `MemoryStorage` хранит незавершённые анкеты в оперативной памяти. После перезапуска они теряются.
- Проверка телефона рассчитана на российские номера `+7` или номера из 11 цифр, начинающиеся с `8`.
- Нет базы данных, личного кабинета и защиты от повторной доставки части заявки.
- Если фотография доставлена, а текст нет, повторная попытка может отправить фото ещё раз.
- Бот предназначен для личных сообщений.

## Безопасность и персональные данные

Анкеты содержат персональные данные, включая телефон и фотографию. Ограничивайте доступ к заявкам, определите срок хранения и получайте необходимые согласия на обработку данных. Не публикуйте токены или данные кандидатов.
